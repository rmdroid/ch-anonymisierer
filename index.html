Zwischen Kopieren und Einfügen liegt ein Sekundenbruchteil.

In Schweizer Kanzleien, Treuhandbüros, Praxen und Verwaltungen stehen in fast jedem Text Angaben, die dem Berufs- oder Amtsgeheimnis und dem Datenschutzgesetz unterstehen.

Niemand kopiert sie aus bösem Willen in einen KI-Chat. Es passiert nebenbei, weil 14 weitere Geschäfte warten. KI-Anonymisierer setzt genau an dieser Stelle an: Die Angaben werden ersetzt, bevor der Text das Haus verlässt.

  • KanzleiKlientinnen und Klienten, Gegenparteien, Dossiernummern
  • TreuhandLohnlisten, Steuerunterlagen, Bankverbindungen
  • PraxisPatientennamen, Geburtsdaten, Diagnosen
  • VerwaltungGesuchstellende, Adressen, Geschäftsnummern

200 Arbeitsplätze brauchen keine 200 KI-Installationen.

KI-Anonymisierer Server bündelt die Erkennung in einem Docker-Dienst, den Sie selbst betreiben. Windows-Client, Chrome-Erweiterung und eigene Anwendungen nutzen ihn über eine gemeinsame Schnittstelle.

So arbeiten Client und Server zusammen

  1. Server betreiben

    Den Docker-Dienst in Ihrem Netz starten, Erkennungsmodule wählen und eigene Begriffe pflegen.

  2. Clients verbinden

    Serveradresse und Zugriffsschlüssel im Windows-Client hinterlegen. Der Schlüssel wird mit Windows-DPAPI verschlüsselt gespeichert.

  3. Kopieren und zustimmen

    Der Client fragt standardmässig, bevor ein kopierter Text an den Server geht.

  4. Bestätigen und ersetzen

    Der Client zeigt die Zahl der Treffer. Erst Ihre Bestätigung ersetzt sie durch Platzhalter.

Pilot anfragen

Ehrliche Antworten.

Verlässt mein Text den Rechner?

Bei den Apps für Mac, iPhone, iPad und Windows sowie in der Chrome-Erweiterung ohne Serveranbindung nicht: Die Erkennung läuft auf Ihrem Gerät. Im Servermodus wird der Text zur Analyse an Ihren selbst betriebenen Server übertragen.

Erkennt die Software alle sensiblen Angaben?

Keine automatische Erkennung ist vollständig. KI-Anonymisierer unterstützt die Prüfung, die Kontrolle vor der Weitergabe bleibt entscheidend.

Ist die Nutzung damit automatisch datenschutzkonform?

Das kann keine Software pauschal zusagen. KI-Anonymisierer reduziert Personendaten, bevor Texte weitergegeben werden. Die rechtliche Beurteilung Ihres Einsatzes bleibt bei Ihnen und Ihrer Datenschutzberatung.

Brauchen wir für mehrere Arbeitsplätze einen Server?

Nicht zwingend. Jeder Arbeitsplatz kann eine eigene App nutzen. Der Server lohnt sich, wenn Sie Erkennung und eigene Begriffe zentral pflegen möchten.

Wie gross muss der Server sein?

Das hängt von Textmengen, Antwortzeiten und gleichzeitigen Anfragen ab. Im Pilot ermitteln wir gemeinsam, was Ihr Einsatz braucht.

Können wir den Server vorher testen?

Ja, 30 Tage kostenlos. Mit dem Testzugang prüfen Sie die Erkennung an eigenen Beispieltexten, ohne Installation, über die Chrome-Erweiterung und unseren Testserver. Bitte nur erfundene Daten verwenden: Für den Testzugang besteht kein Vertrag über die Auftragsbearbeitung.

In welcher Währung wird abgerechnet?

Die Apps kaufen Sie im Schweizer App Store oder Microsoft Store in Franken. Die Teamlizenz für den Mac, die Server-Lizenz und der Excel-Anonymisierer werden derzeit in Euro offeriert.
